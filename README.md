# 📚 Bookshop

Интерактивная страница интернет-магазина книг, созданная с нуля.

## 🔗 Демо
[Открыть проект в браузере](https://madina-di.github.io/Bookshop/)

## 🧩 Описание проекта
Bookshop — одностраничный лендинг, демонстрирующий динамическую загрузку книг по категориям с использованием JavaScript. Проект выполнен в современном минималистичном дизайне с акцентом на удобство пользователя.

### Функциональность:
- Переключение между категориями книг
- Слайдер с баннерами
- Отображение карточек книг
- Адаптивная вёрстка
- Работа с JSON API

## ⚙️ Стек технологий
- HTML / Pug
- SCSS (Sass)
- JavaScript (ES6+)
- Webpack
- GitHub Pages

## 🚀 Установка и запуск

Установка зависимостей:
```bash
npm install

Запуск в режиме разработки:
npm run dev

Сборка проекта:
npm run build

Публикация на GitHub Pages:
npm run deploy

📁 Структура проекта
